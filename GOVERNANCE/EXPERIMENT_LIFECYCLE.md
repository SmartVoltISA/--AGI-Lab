# Жизненный цикл эксперимента

Экспериментальный организм является временным инструментом. Канонический организм защищён от прямых изменений.

```text
CANONICAL
   ↓ snapshot / reference
EXPERIMENTAL ORGANISM
   ↓ hypothesis → implementation → run
OBSERVATION → RESULT
   ↓
ARCHIVE RESULT + JOURNAL
   ↓
DELETE EXPERIMENTAL ORGANISM
   ↓
CANONICAL UNCHANGED
   ↓
если результат подтверждён → отдельное архитектурное предложение
   ↓
независимая проверка
   ↓
только затем возможное изменение CANONICAL
```

## Обязательные правила

1. Эксперимент не изменяет код, состояние, память, архитектуру или конфигурацию канона.
2. Экспериментальный организм создаётся отдельно и после опыта удаляется.
3. Сохраняются гипотеза, протокол, параметры, raw observations, результаты, ошибки и выводы.
4. Успешный опыт не означает автоматического включения результата в канон.
5. Любое архитектурное следствие оформляется отдельным предложением.
6. Перед переносом в канон результат должен пройти независимую проверку.
7. После эксперимента проверяется отсутствие временного кода и состояния и неизменность канона.

## Статусы

`PROPOSED → EXECUTED → SUCCESS / FAILURE / INCONCLUSIVE`

`NOT EXECUTED` используется явно, если запуск не состоялся.

## Правило

**Эксперимент временный. Доказательство постоянное.**
