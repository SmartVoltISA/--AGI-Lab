# EXP-0019 — Primary Summary

## Classification
**PILOT / INCONCLUSIVE**

The mechanism is preserved as a research target, but the earlier exploratory run occurred before the formal protocol was committed and its raw data were not retained. It is therefore not promoted to a reproducible success claim.

## Mechanism preserved
The experiment formalizes a causal-diagnostic primitive:

`failure → hypothesis space → candidate tests → expected information gain → test → evidence → posterior update → next test`

The important distinction is between **repeating an action** and **obtaining discriminating evidence**. A diagnostic system should spend its limited actions on tests that eliminate or separate causal hypotheses.

## Preliminary local observation
An exploratory Bayesian/noisy simulation with ten causes and four binary diagnostic tests showed that information-guided selection could improve accuracy and, under some noise settings, reduce average test count/cost relative to a fixed sequence. Those observations motivated formalization but are explicitly not treated as final evidence because the run preceded protocol registration and its raw dataset was not retained.

## Decision
Do not discard the mechanism. Preserve the protocol and research direction. Execute a clean post-registration run before making a SUCCESS classification.
