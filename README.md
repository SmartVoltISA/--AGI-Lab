# --AGI-Lab

Экспериментальная лаборатория для проверки архитектуры интеллекта, обучения, памяти, мотивации и адаптации до внесения изменений в канонический организм.

## Назначение

`--AGI` — канонический организм.

`--AGI-Lab` — отдельный экспериментальный контур, где гипотезы можно реализовывать, ломать, сравнивать и проверять без загрязнения канона.

## Принцип

```text
КАНОН
  ↓
гипотеза
  ↓
ЭКСПЕРИМЕНТ
  ↓
наблюдение → проверка → результат
  ↓
решение
  ↓
при подтверждении — отдельное предложение
  ↓
независимая проверка
  ↓
КАНОН
```

Канонический организм не меняется автоматически по результатам одного эксперимента.

## Правила доказательности

- UNKNOWN ≠ TRUE
- HYPOTHESIS ≠ VERIFIED
- PROPOSED ≠ EXECUTED
- EXECUTED ≠ SUCCESSFUL
- RESULT ≠ CANONICAL
- неудача сохраняется как evidence;
- временный экспериментальный организм после эксперимента удаляется;
- результаты, параметры, наблюдения и выводы сохраняются.

## Текущий исследовательский фокус

Минимальный замкнутый контур обучения:

`WORLD → PERCEPTION → STATE → MODEL / RELATIONS → PREDICTION → ERROR / SURPRISE → ACTION → RESULT → MEMORY + MODEL UPDATE`

Следующий экспериментальный фокус — проверить, даёт ли внутренняя значимость и мотивационно-аффективная петля измеримое преимущество в адаптации, переключении стратегии и переносе.
